## The project

This is a deletion-audit agent for the HackerRank Orchestrate challenge "Ghost Data Still Exists". The repository root is `C:\Users\shoer\hackerrank-orchestrate-october26`.

For each deletion request (`case_id, email, requested_at, reported_status, reported_at, audit_at, request_text`), the agent decides whether deletion is authorized. If it is, the agent:
- resolves the person's current and historical identifiers
- finds every record of theirs across the evidence
- reconstructs each record's state at `audit_at`
- applies `dataset/deletion_rules.csv`
- outputs `deletion_status` (COMPLETE / INCOMPLETE / NOT_APPLICABLE) and an ordered `steps_json` list (FINDING → REMEDIATION → VERIFICATION, each step citing an `evidence_id`)
