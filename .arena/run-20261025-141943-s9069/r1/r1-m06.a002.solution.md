## Predicted effect and regression risk

With no code change, the expected effect is zero additional exact matches among the 32 samples and no changes to the 22 samples that already match exactly. This is a prediction based on the unchanged code, not a newly measured result. I attempted the prescribed sample run environment check: `python --version` could not start the Windows Store alias, and `py -3.11 --version` reported that no Python installation is available. Therefore fresh scoring and the regression suite could not be run, and I do not claim they passed. Any heuristic change would have an unknown effect on the other samples and hidden cases; the known risk is false ownership attribution.

## Ranked recommendation

1. Keep the conservative behavior until participant-facing evidence links each missing resource to its requester or proves the absence/presence in scope.
2. If these expected steps are intended to be inferable, improve the evidence pipeline to expose unique subject links or scoped state evidence for the account and anonymous analytics records.
3. Evaluate any future general rule on all 32 samples and the full hidden-like regression set before adoption. Do not tune to the answer file.
